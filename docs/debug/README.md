## 🚀 快速排查流程

### 数据问题
1. 检查 [数据来源调试](./DEBUG_DATA_SOURCE.md) - 确认数据来源
2. 检查 [Supabase 调试](./DEBUG_SUPABASE.md) - 验证数据库连接
3. 尝试 [清除缓存重试](./CLEAR_CACHE_AND_RETRY.md) - 排除缓存问题

### 显示问题
1. 检查浏览器控制台错误信息
2. 查看对应的调试文档
3. 尝试清除缓存和本地存储

---

## 💡 调试技巧

- **浏览器控制台**：F12 打开开发者工具，查看 Console 和 Network 标签
- **Supabase Dashboard**：查看 Logs 和 Table Editor
- **网络请求**：检查 Network 标签中的 API 请求状态
