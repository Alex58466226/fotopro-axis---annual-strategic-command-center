## 🚀 快速开始

### 首次配置 AI 功能
1. 阅读 [AI 配置说明](./AI_CONFIG.md) 了解支持的模型
2. 根据需求选择模型（推荐 Gemini）
3. 按照对应的设置指南配置 API Key
4. 验证配置是否成功

### 推荐配置
- **开发环境**：Gemini（免费额度高）
- **生产环境**：根据需求选择（Gemini/OpenAI/DeepSeek）
