### 2. 核心功能测试

#### 认证功能
1. **登录测试**
   - 使用默认用户：`admin` / `admin123`
   - 测试错误提示（错误密码）
   - 刷新页面，验证登录状态持久化

2. **注册测试**
   - 注册新用户
   - 测试密码确认验证
   - 测试用户名重复检查

3. **忘记密码**
   - 测试模式切换
   - 测试表单显示

#### 侧边栏功能
1. **策略树**
   - 展开/折叠节点
   - 点击节点切换活动策略
   - 验证 L1-L3 层级显示

2. **任务节点**
   - 验证任务状态图标
   - 点击任务打开编辑 Modal

3. **用户资料**
   - 显示当前用户信息
   - 测试登出功能
   - 测试用户管理入口（Admin）

#### 主内容区
1. **Header**
   - 验证策略详情显示
   - 验证统计数据
   - 测试操作按钮

2. **FilterPanel**
   - 测试筛选条件
   - 验证筛选结果实时更新

3. **GanttChart**
   - 验证甘特图渲染
   - 测试时间轴缩放
   - 测试折叠/展开

4. **TaskList**
   - 验证任务列表显示
   - 测试任务状态更新
   - 测试任务编辑/删除
   - 测试 AI 辅助（L3 层级）

#### Modal 功能
1. **MapModal**
   - 打开架构地图
   - 测试节点展开/折叠
   - 测试节点点击切换
   - 测试任务点击编辑

2. **StrategyModal**
   - 创建新策略
   - 编辑现有策略
   - 测试标签快捷选择
   - 测试父节点选择

3. **TaskModal**
   - 编辑任务详情
   - 添加/编辑/删除报告
   - 管理执行清单
   - 验证数据保存

4. **ReportModal**
   - 测试 AI 生成周报
   - 手动编辑报告项
   - 测试复制到剪贴板

5. **UserManagementModal**
   - 查看用户列表
   - 添加用户
   - 删除用户
   - 验证权限控制（仅 Admin）

6. **AuditLogModal**
   - 查看审计日志
   - 测试筛选功能

#### 数据持久化
1. **策略数据**

2. **任务数据**
